# Michael — studio site

Personal portfolio for **Khureltulga Gantsetseg (Michael)** — creative director and marketing designer.

## Run

```bash
cd michael-studio
npm install
npm run dev
```

Open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

Static output lands in `dist/`. Deploy that folder to any static host (Netlify, Vercel, Cloudflare Pages, GitHub Pages).

## Pages

- `/` — home
- `/work.html` — index
- `/about.html` — story + experience
- `/contact.html` — inquiry form (opens mail)
- `/work/insomnus.html`, `/work/mintpark.html`, `/work/ordinals.html`, `/work/somegorillas.html`
